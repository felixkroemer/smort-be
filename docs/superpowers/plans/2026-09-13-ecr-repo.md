# ECR Repository + ECS Image Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provision an ECR repository for smort and point the existing ECS task at an image from that repository, all in Terraform.

**Architecture:** Add a new `ecr` Terraform module mirroring the existing `vpc`/`alb`/`ecs` module style. Wire it into the root `terraform/main.tf` so the ECS task's `container_image` is derived as `${module.ecr.repository_url}:${var.image_tag}`. Only the image tag is a variable; the repo URL/domain always comes from the module output. No changes to the `ecs` module (its exec role already grants ECR pull).

**Tech Stack:** Terraform (`hashicorp/aws ~> 5.0`), AWS ECR, ECS Fargate.

## Global Constraints

- Region: `eu-central-1`; provider `hashicorp/aws ~> 5.0`.
- All resources tagged via root provider `default_tags` (`Project = "smort"`); explicit `Name` tags follow the `${var.name}-...` convention.
- `container_image` passed to `module.ecs` MUST be exactly `"${module.ecr.repository_url}:${var.image_tag}"`.
- ECR repository: `image_tag_mutability = "MUTABLE"`, `scan_on_push = true`.
- ECR lifecycle policy keeps the most recent `max_image_count` images (default 5).
- No changes to `terraform/modules/ecs/` files.
- No automated Terraform tests; no build/compile steps (AGENTS.md — human owns the build).

### Task 1: Create the ECR module

**Files:**
- Create: `terraform/modules/ecr/main.tf`
- Create: `terraform/modules/ecr/variables.tf`
- Create: `terraform/modules/ecr/outputs.tf`

**Interfaces:**
- Consumes: nothing (standalone module).
- Produces: `var.name` (string), `var.max_image_count` (number, default 5); outputs `repository_url` (string) and `repository_name` (string).

- [ ] **Step 1: Create `terraform/modules/ecr/variables.tf`**

```hcl
variable "name" {
  type        = string
  description = "ECR repository name."
}

variable "max_image_count" {
  type        = number
  description = "Maximum images to retain before the lifecycle policy expires older ones."
  default     = 5
}
```

- [ ] **Step 2: Create `terraform/modules/ecr/main.tf`**

```hcl
resource "aws_ecr_repository" "this" {
  name                 = var.name
  image_tag_mutability = "MUTABLE"

  image_scanning_configuration {
    scan_on_push = true
  }

  tags = { Name = "${var.name}-ecr" }
}

resource "aws_ecr_lifecycle_policy" "this" {
  repository = aws_ecr_repository.this.name

  policy = jsonencode({
    rules = [
      {
        rulePriority = 1
        description  = "Keep the most recent images"
        selection = {
          tagStatus   = "any"
          countType   = "imageCountMoreThan"
          countNumber = var.max_image_count
        }
        action = {
          type = "expire"
        }
      }
    ]
  })
}
```

- [ ] **Step 3: Create `terraform/modules/ecr/outputs.tf`**

```hcl
output "repository_url" {
  value = aws_ecr_repository.this.repository_url
}

output "repository_name" {
  value = aws_ecr_repository.this.name
}
```

- [ ] **Step 4: Format check**

Run: `terraform fmt -check terraform/modules/ecr/`
Expected: exits 0 (no formatting diffs). If it fails, run `terraform fmt terraform/modules/ecr/` and re-check.

- [ ] **Step 5: Commit**

```bash
git add terraform/modules/ecr
git commit -m "chore(infra): add ecr module"
```
